# Forestry_RS
🌳 Forestry &amp; Environmental Data Repository: Code and spatial scripts for forest conservation, ecosystem monitoring, and environmental protection. Powered by Python, R &amp; GEE.
## 🍃 Fokus Riset & Kode

* **Pemantauan Ekosistem Hutan:** Deteksi tutupan pohon (*tree canopy cover*), deforestasi, dan analisis laju degradasi lahan.
* **Konservasi & Keanekaragaman Hayati:** Pemetaan habitat satwa, koridor ekologi, dan kesehatan vegetasi hutan.
* **Biomassa & Karbon Hutan:** Estimasi stok karbon vegetasi dan kalkulasi indeks lingkungan berbasis data satelit.
* **Restorasi & Pemulihan Lahan:** Analisis perubahan lahan pasca-kebakaran hutan dan pemantauan area reboisasi.

---

## 🛠️ Tools & Bahasa Pemrograman

* **Python** (`GeoPandas`, `Rasterio`, `xarray`, `scikit-learn`)
* **R** (`terra`, `sf`, `raster`, `tmap`)
* **Google Earth Engine (GEE)** (Skrip Javascript & Python API)
* **GIS Automations** (PyQGIS & ArcPy)
